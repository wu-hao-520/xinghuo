# 试卷题目分析

## 概述

本技能用于逐题分析小初高阶段（小学、初中、高中）语文、数学、英语、物理、化学五大学科的试卷。针对用户提供的试卷图片或文件，提取每一道题，并从五个维度进行结构化分析：难度、考点、知识点、题型、解题方法。

## 适用场景

以下情况应触发本技能：

- 用户上传试卷图片（拍照 / 截图 / 扫描件）或文件（PDF、Word、TXT 等），要求分析题目。
- 用户要求评估题目难度、划分难易等级。
- 用户要求梳理考点、知识点、命题范围。
- 用户要求归纳题型（选择、填空、解答、实验、阅读理解等）。
- 用户要求讲解解题方法、思路或技巧。
- 用户要求生成试卷分析报告、逐题解析表。
- 用户提供“标准中间题目包”（如 `exam-conversion-v1` JSON/ZIP），要求整理、理解、去重、规范化标签或纳入题库。

## 分析流程

按以下步骤逐题分析，最后汇总：

### 第一步：识别试卷与题目

1. 从用户提供的图片或文件中读取全部题目内容。
   - 图片：直接查看图片内容，识别题干、选项、图表、小题。
   - 文件：PDF 用 pdf 技能解析，Word 用 docx 技能解析，提取文字与图表。
   - **Word 公式格式检测（重要避坑）**：提取 docx 前先检查 `word/document.xml`——若 `oMath` 数量为 0 且存在 `word/embeddings/oleObject*.bin`（MathType OLE 对象），说明公式不在文本层（`extract_docx.py` 会**丢失全部公式**）。此时改走**视觉识别路线**：渲染配套 PDF（或 docx 转 PDF）逐页读图，公式由 AI 视觉转录为 LaTeX；几何图从 `word/media/` 提取 png/jpg（wmf/emf 是公式图，跳过）。数学教辅 docx 多为 MathType 格式，务必先检测。
2. 确认学科（语文 / 数学 / 英语 / 物理 / 化学）与学段（小学 / 初中 / 高中）。
3. 将试卷切分为独立题目，按题号编号（大题 + 小题，如「第 21 题(2)」）。
4. 若图片模糊、缺页或无法识别某题，向用户说明并请求补充，不要臆测。

### 第二步：逐题五维分析

对每一道题，从以下五个维度输出分析：

1. **难度**：分为「基础 / 中等 / 较难 / 难题」四级。
   - 依据：考查知识点的单一性/综合性、思维深度、计算量、是否含易错点或陷阱。
2. **考点**：该题直接考查的考试命题点（如「二次函数的最值」「受力分析」「定语从句」）。
3. **知识点**：题目背后涉及的具体知识内容（可能比考点更细，或包含前置知识）。
4. **题型**：如选择题、填空题、计算题、解答题、实验探究题、阅读理解、写作、翻译等。
5. **解题方法**：给出通用的解题思路、步骤或技巧（公式、模型、口诀、易错提醒）。

### 公式书写规范（重要）

分析输出中涉及数学、物理、化学公式时，**一律使用 LaTeX 公式语法**，不要使用 Unicode 上下标字符：

- **行内公式**用 `$...$`，如 `$E_4$`、`$v_0$`、`$B^2L^2$`、`$\frac{1}{2}mv_0^2$`。
- **块级公式**用独立一行 `$$...$$`，如 `$$F=ma$$`。
- **上下标**用 `_{}` 和 `^{}`，如 `$t_1$`、`$v_0$`、`$10^{-3}$`、`$^{235}_{92}\mathrm{U}$`。
- **分数**用 `\frac{}{}` 或 `\dfrac{}{}`（表格内建议 `\dfrac` 保持清晰），如 `$\frac{B^2L^2v_0}{mR}$`。
- **希腊字母**用 `\alpha \beta \lambda \theta \varphi \Delta \Phi` 等，如 `$\lambda=h/p$`、`$\Delta\Phi=BL^2$`。
- **物理量符号**用正体包裹单位/元素，如 `$\mathrm{eV}$`、`$\mathrm{U}$`、`$\mathrm{m/s^2}$`。

**禁止事项**：
- ❌ 不使用 Unicode 上下标字符（`₁₂₃₄₀ₐₚ⁰¹²³` 等）——这些字形不完整、渲染不一致、部分字体缺字形。
- ❌ 不使用 `_A`、`_b` 式伪下标（`φ_A`、`E_b`）——统一改为 `$\varphi_A$`、`$E_b$`。

**适用范围**：本规范适用于 Markdown 报告，以及导出 Word/Excel 时公式内容的表达。若用户查看环境不支持 LaTeX 渲染，可退化为可读的线性写法（如 `E4-E2`），但默认优先 LaTeX。

**Excel 导出专用（重要）**：Excel 单元格不支持 LaTeX 渲染，应改用**富文本上下标**（openpyxl 的 `CellRichText` + `InlineFont(vertAlign="subscript"/"superscript")`）做真正的上下标：
- 下标用 `vertAlign="subscript"`，上标用 `vertAlign="superscript"`。
- 写富文本时可用临时标记语法（如 `~下标~`、`^上标^`）再由脚本解析，但**标记符 `~` 不能与「区间符号 ~」冲突**——区间（如 $0 \sim t_0$）改用全角 `～` 或 `-`，避免和下标标记混淆。
- 分数无法做真分式，保留线性写法（如 `B^2^L^2^v~0~/(mR)`），但其中的上下标仍用富文本上下标呈现。

### 第三步：输出分析结果

默认使用**逐题表格**呈现，结构如下（列名可微调）：

| 题号 | 难度 | 考点 | 知识点 | 题型 | 解题方法 |

表格之外，按需补充以下汇总信息：

- **试卷整体概况**：学科、学段、满分、题量、各难度题量分布。
- **知识板块分布**：按章节/模块统计考点分布，指出高频考点。
- **重难点提示**：标注压轴题、易错题、区分度高的题目。

### 第 3.4 步：标准中间题目包导入（AI-1 → AI-2 分层）

当用户提供外部转换好的“标准中间题目包”（常见为 `.zip`，内含 `package_manifest.json`、各试卷 `manifest.json` / `questions.json`、`figures/`、`original/`）时，按以下规则处理：

1. **职责分层**：把中间题包视为 AI-1 的“事实还原层”输出；本 Skill 只做 AI-2 的“题库理解 / 整理层”，包括内容核验、知识点、方法、难度、能力、答案解析、去重、标签规范化和正式入库。
2. **先验包体检**：先读取 `package_manifest.json` 与各 `questions.json`，检查题数、`schema_version`、`paper_id`、`question_id`、`source`、`content`、`figures`、`original_image`、`conversion.confidence`、`conversion.requires_review`、`conversion.issues` 是否完整；不要直接跳过清单校验。
3. **LaTeX 反斜杠保护（重要避坑）**：中间题包与题库 JSON 中所有 LaTeX 命令必须保留双反斜杠形式（JSON 文件里看到 `\\frac`、`\\angle`、`\\text`、`\\neq`），严禁让 `\f`、`\a`、`\t`、`\n` 被解释成控制字符；导入前后都要抽查公式字段，若出现 `rac`、`ngle`、`ext`、`:eq` 或不可见控制字符，必须先清洗再入库/出卷。
4. **图片路径规则（重要）**：中间包配图复制到分库内 `images/{试卷名}/figures/`，原题截图复制到 `images/{试卷名}/original/`；题目 `images` 与 `original_image` 字段统一存**相对分库根目录**路径，如 `images/{试卷名}/figures/Q05-F01.png`，不要存裸文件名，也不要重复成 `images/images/...`。
5. **答案来源**：若中间题包 `answer_raw` / `solution_raw` 为空，需要 AI-2 补答案解析并标注 `answer_source: "AI解答（待教师确认）"`、`review_status: "待教师确认"`；不得伪装成 `真题答案`。
6. **去重规则**：优先按 `source_paper + question_no` 跳过重复；若来源名变化但 `raw_item_id` 相同，也视为重复候选，需人工判断或保留警告。
7. **导入后体检**：导入完成必须运行 `validate_question_bank.py`；若发现历史存量问题，可顺手做结构性修复，但需在交付中说明。
8. **标准题包快速入库优先用脚本（重要提速）**：对已经转换好的标准中间题目包，优先运行 `scripts/import_standard_package.py`，不要临时手写 `python -c` 或一次性导入脚本；凡是可重复使用的逻辑，必须固化到 `scripts/` 下的正式脚本。Windows 中文路径/中文参数容易在 PowerShell 中被 GBK 破坏，优先使用 `--download-name "文件名.zip"` 从下载目录按文件名定位，或用 `--latest-download` 自动取下载目录最新 zip；不要再为单次中文路径创建 `_tmp/` 包装脚本。脚本负责包体检、LaTeX 控制字符污染拦截、分库定位、配图/原题截图复制、全局 ID 分配、`_papers.json` / `_meta.json` / `_index.md` 更新。若题包无答案，快速入库时先写 `answer: "待教师确认"`、`answer_source: "未提供（待补答案）"`，后续再批量补答案解析；不要因即时补完整答案而阻塞录入。

### 第 3.5 步：题目入库（批量建题库）

分析完成后，把每道题写入统一题库 `e:\codebuddy\workflow\question-bank\`（**分库架构：按年级/科目分库存放**）：

1. **分库定位**：按试卷的 `grade` + `subject` 定位分库 `question-bank/{年级}/{科目}/`（如 `高三/物理/`、`初三/数学/`），分库不存在时先创建（含 `images/` 子目录）。库内三个文件：`_questions.json`（题目）、`_papers.json`（试卷清单）、`images/{试卷名}/`（插图）。
2. **id 全局唯一（重要）**：`Q-` + 5 位序号由**根级 `_meta.json` 的 `next_id` 统一分配**——先读 `question-bank/_meta.json` 取 `next_id`，顺序编号，写完把 `next_id` 更新为「最后一个 id + 1」写回。**跨库绝不重复**（两个库里出现同一个 id 是严重错误）。超过 95000 时评估扩位。
3. **题目结构化**：为每道题生成一条记录，字段如下（**必须包含来源字段** `exam_date` 和 `exam_type`）：

```json
{
  "id": "Q-00323",
  "subject": "物理",
  "grade": "高三",
  "source_paper": "顺德一中第四届物理运算",
  "exam_date": "2026-09-05",
  "exam_type": "模拟考",
  "question_no": "第8题",
  "question_text": "题干",
  "options": ["A...", "B...", "C...", "D..."],
  "answer": "AD",
  "analysis": "解析",
  "knowledge_point": "电磁感应",
  "exam_point": "安培力、磁通变化、电量",
  "difficulty": "难题",
  "question_type": "多选题"
}
```

**来源字段说明（重要）**：
- `exam_date`：考试日期（`YYYY-MM-DD`）。
- `exam_type`：考试类型，取值规范为以下枚举之一——`月考`、`期中`、`期末`、`中考`、`高考`、`模拟考`（可细分一模/二模/三模）、`联考`、`周测`、`单元测试`、`其他`。
- **来源信息以教师告知为准**：教师提供试卷时会说明"这是哪次考试"，若未说明，向教师询问或标注 `exam_type: "待确认"`，不要臆测。

4. **写入分库 `_questions.json`**：追加（去重：相同 `source_paper` + `question_no` 已存在则跳过，不重复）。
5. **写入分库 `_papers.json`**：记录本次试卷元信息（试卷名、学科、学段、`exam_date`、`exam_type`、题量）。
6. **更新全局 `_index.md`**：重新生成根级题库概览（聚合各分库统计：按年级/科目/题型/难度）。
7. **录入后必须跑体检（重要）**：每次题目入库后执行结构性校验，确认 0 错误再交付：

   ```
   python .codebuddy/skills/exam-paper-analyzer/scripts/validate_question_bank.py
   ```

   自动遍历全部分库，校验 id 跨库唯一/字段/枚举/选项答案匹配/去重/图片引用/试卷清单一致/配图覆盖/归属正确。注意：**结构校验 ≠ 语义校验**——答案对不对、解析准不准仍需人工核对。
8. **插图保存（重要，出题需要）**：试卷中的插图（题目配图、电路图、示意图等）必须**完整保存**，并在题目记录中关联：
   - 图片存到**分库内** `question-bank/{年级}/{科目}/images/{试卷名}/`（按试卷分子目录）。
   - Word（docx）：从 `word/media/` 提取图片，通过 `word/_rels/document.xml.rels` 解析 `rId → media 文件名` 映射，再根据图片所在段落位置判断归属题号。
   - PDF：用 pdf 技能抽取内嵌图片，或用 pypdfium2 渲染页面后截图（整页图需人工/视觉判断题目归属）。
   - 题目记录新增 `images` 字段（数组），存放相对路径，如 `["images/2025高考广东卷/image4.png"]`。
   - 图片文件名保持稳定（用原序号或题号+序号），便于后续出题引用。

> 说明：试卷分析成果（逐题报告）仍存 `exam-paper-output/`，题目入库是**额外动作**，两者都要做，便于后期检索、组卷、错题出题复用。

> **答案来源标注（重要）**：每题必须带 `answer_source` 字段，取值枚举——`真题答案`（原卷/教师版自带答案）、`AI解答（待教师确认）`（图片/学生版无答案时，由 AI 解答生成且完成自检）、`教师确认`（AI 解答经教师核对）、`未提供（待补答案）`（标准中间题包快速入库时原包无答案，尚未补 AI 解答）。**无答案题包允许先快速入库再补答案解析**，但出给学生练习前必须补齐或经教师确认；绝不能把待补答案伪装成真题答案。

### 第四步：自我总结与 Skill 优化（每次运行必做）

每次分析结束后，必须做一次自我复盘，把踩到的坑沉淀为 Skill 的改进：

1. **回顾本次运行**：是否有踩坑（如 PDF 扫描件无文字层、中文路径/目录乱码、图片模糊、格式、脚本 bug）、重复劳动、低效绕路、可复用的一次性脚本。
2. **判断是否值得优化**：凡是「下次还会遇到」的问题，都应固化为 Skill 的规则或脚本修复，而不是每次临场试错。
3. **落盘优化**（任选适用的动作）：
   - 更新 `SKILL.md`（补一条避坑规则 / 流程说明）；
   - 更新 `references/` 参考文档（如补充学科分析要点、易错点）；
   - 追加 `CHANGELOG.md` 变更记录（**不写入试卷分析成果**）。
4. **清理临时文件（一键，勿逐个删）**：遵循工作区统一「临时文件规范」——运行中的一次性脚本、中间产物统一放入工作区 `_tmp/` 目录（已被 `.gitignore` 排除，可按用途建子目录如 `_tmp/extract/`），禁止散落在根目录或正式数据目录。结束时执行**一条命令**清理，禁止逐个文件删除（会多次打扰用户确认）：

   ```
   python .codebuddy/scripts/cleanup_tmp.py
   ```

   支持 `--dry-run`（预览不删）与 `--legacy`（额外清理根目录遗留 `*_work/` 目录）。脚本只删 `_tmp/`，绝不触碰 `.codebuddy/`、`question-bank/`、`exam-paper-output/` 等正式目录。
5. **优先复用已有脚本（避免重复劳动）**：本 Skill 的 `scripts/` 已沉淀以下工具，运行时**先用现成的**，不要临场重写：
   - `scripts/extract_docx.py`：docx 试卷 → 结构化题目（**OMML 公式完整转 LaTeX**，含 `omml2latex.py`），比手写正则提取 `<m:t>` 文本可靠得多；
   - `scripts/latex2omml.py`、`scripts/render_docx_practice.py`：公式/导出工具。
6. **原则**：把「一次性试错」变成「永久规则」，让下一次运行不再重蹈覆辙。

#### Skill 变更记录同步输出

若本次使用过程中对 Skill 自身（脚本 / 参考文档 / SKILL.md）做过任何修改，必须：
1. 将改动追加记录到 `CHANGELOG.md`（格式见该文件顶部说明，新条目放在「变更历史」下方最新位置）；
2. 维护记录**仅保留在 `CHANGELOG.md`，不写入最终的试卷分析成果**——分析成果只面向用户交付试卷分析内容，不含 Skill 维护细节。

## 输出文件保存规范

分析完成后，将成果（逐题分析表、汇总报告等）保存为文件，统一存放到成果目录 `e:\codebuddy\workflow\exam-paper-output\` 下，并按学科分子目录分类：

| 学科 | 保存目录 |
|------|----------|
| 语文 | `exam-paper-output\语文\` |
| 数学 | `exam-paper-output\数学\` |
| 英语 | `exam-paper-output\英语\` |
| 物理 | `exam-paper-output\物理\` |
| 化学 | `exam-paper-output\化学\` |

保存约定：

1. 根据试卷所属学科选择对应子目录；子目录不存在时先创建。
2. 文件命名建议：`{年级}_{试卷名或日期}_题目分析.md`，例如 `初三_2026期末数学_题目分析.md`。
3. 默认以 Markdown（`.md`）保存；如用户要求 Word、Excel 等其他格式，再改用 docx / xlsx 技能生成。
4. 目录名使用中文（语文/数学/英语/物理/化学），创建目录时避免因终端编码导致乱码，应使用 UTF-8 编码方式创建。

## 学科分析要点

分析时结合学科特点（详见 `references/subject-guide.md`，可按需查阅）：

- **语文**：现代文阅读（主旨、手法、作用）、古诗文（意象、情感、翻译）、语言文字运用（病句、成语）、写作（审题、立意、结构）。
- **数学**：代数（函数、方程、不等式）、几何（证明、计算、图形性质）、概率统计、应用题建模；注重一题多解与通法。
- **英语**：词汇语法（时态、从句、非谓语）、阅读理解（主旨、细节、推断）、完形填空、写作；注重语境与语篇。
- **物理**：力学、电学、热学、光学、近代物理；注重物理模型、受力分析、过程分析、单位与公式适用条件。
- **化学**：基本概念、物质性质、化学方程式、实验、计算；注重守恒思想、方程式配平、实验操作规范。
