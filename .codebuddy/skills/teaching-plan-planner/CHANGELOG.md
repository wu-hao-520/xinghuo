# Skill 变更记录（CHANGELOG）

本文件记录 `teaching-plan-planner` 这个 Skill 在**每次实际使用过程中对自身**
（结构 / 功能 / 脚本 / 参考文档 / SKILL.md）所做的修改。

## 为什么需要这份记录

- 后期优化 Skill 时，能快速知道「哪些部分被动过、为什么动」，避免盲目改动主体结构导致功能损坏。
- 维护记录仅保留在本文件，不写入最终的教学计划成果。

## 记录格式（每次修改追加一条）

```text
### YYYY-MM-DD
- **改动位置**：<文件 / 章节 / 脚本名>
- **改动内容**：<做了什么>
- **改动原因**：<为什么>
```

> 追加新条目时请放在「变更历史」下方的最新位置（即紧跟在本说明之后），保持从新到旧排列。

## 变更历史

### 2026-09-06
- **改动位置**：`references/output_format.md`、吴天豪秋季教学计划
- **改动内容**：去除课堂重点中“讲解《某某教案》”这类过程性说明；调整“当堂课掌握情况”列宽与行高，使长文本反馈更适配打印阅读
- **改动原因**：用户要求课堂重点只呈现教学内容本身，掌握情况列需要更适合承载详细分析

### 2026-09-06
- **改动位置**：`SKILL.md`、`references/output_format.md`、吴天豪秋季教学计划
- **改动内容**：固化“修改后续教学计划前，必须详细阅读接下来 2-3 份教案”的流程；课堂重点需写明优先掌握知识点、优先题型和优先题目，并结合已记录的当堂掌握薄弱点滚动调整
- **改动原因**：用户要求先前提供的教案库必须纳入后续教学计划修改依据，不能只做泛泛课次概括

### 2026-09-06

- **改动原因**：用户澄清错题不是课堂重点，而是用于沉淀学生掌握薄弱点，作为后续复习与教学计划调整依据
