# 薄弱点与教案匹配规则（排课优先级算法）

## 核心原则

教学计划的本质是「把有限的课次，优先分配给能解决学生薄弱点的教案」。

## 薄弱点优先级判定

从学生错题数据聚合薄弱知识点后，用以下规则定优先级：

| 优先级 | 判定条件 |
|--------|---------|
| 🔴 高 | 出错 ≥ 2 次，或属于「难题/较难」且错误类型为「概念不清/方法不会」 |
| 🟡 中 | 出错 1 次，或属于「中等/较难」但错误类型为「计算失误/审题」 |
| 🟢 低 | 出错 1 次且为「粗心」，或仅出现在听评课反馈中 |

## 教案匹配打分

对每份教案，与学情快照比对，计算匹配分：

```
匹配分 = 覆盖薄弱点得分 + 难度适配分 + 阶段目标贴合分
```

1. **覆盖薄弱点得分**（最高权重）：
   - 教案知识点命中「高优先级薄弱点」：+3 分/个
   - 命中「中优先级薄弱点」：+2 分/个
   - 命中「低优先级薄弱点」：+1 分/个
   - 无命中：0 分

2. **难度适配分**：
   - 教案难度与学生薄弱点难度「同档」：+2
   - 教案难度比薄弱点「低一档」（利于打基础）：+1
   - 教案难度过高（学生基础不够）：-1

3. **阶段目标贴合分**：
   - 教案内容直接服务阶段目标（如"期中巩固"）：+1
   - 与目标无关：0

## 排课顺序算法

1. 按匹配分从高到低排序教案。
2. 高优先级薄弱点对应的教案**必须排入**（即使课次紧张）。
3. 同分教案按「难度递进」排序：基础 → 中等 → 较难 → 难题。
4. 每 3-4 节正课，插入 1 节「复习/查漏」课（不排新教案，用于回顾前几课薄弱点）。
5. 若教案数 > 可用课次，优先保留匹配分高的，其余标记「跳过」。

## 选用/跳过决策

| 情况 | 决策 | 理由 |
|------|------|------|
| 匹配分高（≥4） | 选用 | 直接针对薄弱点 |
| 匹配分中（2-3） | 可选用 | 巩固或拓展 |
| 匹配分低（≤1） | 跳过 | 与当前学情/目标无关 |
| 学生已掌握（错题 0 次且成绩好） | 跳过 | 不必重复 |

## 特殊情况处理

- **学生基础特别薄弱**：即使教案难度匹配，也建议先降一档（选更基础的教案或补前置知识）。
- **可上课次数很少（≤3）**：只排最高优先级的薄弱点，砍掉所有拓展内容。
- **教师有明确指定**：教师说"这次必须讲 X"，则 X 教案优先排入，其余再按算法补。
