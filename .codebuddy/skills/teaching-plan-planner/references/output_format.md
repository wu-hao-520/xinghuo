# 教学相关 Excel 输出统一规范

教学计划、阶段规划、课次安排、学情摘要等教学相关表格型成果，默认输出为 Excel `.xlsx`，并优先适配 A4 打印。

## 工作簿结构

建议至少包含以下工作表：

1. **课次计划**：核心工作表，按课次排列。
2. **学情摘要**：学生基本情况、成绩、薄弱点、阶段目标。

如任务较简单，可只输出一个工作表；如用户明确要求 Word/PDF，再另行生成。

## 课次计划表结构

| 课次 | 教学主题 | 课堂重点 | 当堂课掌握情况 |
|------|----------|----------|----------------|

要求：
- 「课堂重点」写清本节课真正讲什么、解决什么问题，不只写知识点名称；不要把错题清单直接塞进课堂重点，也不要写“讲解《某某教案》”这类过程性说明。
- 修改未来课次安排时，必须详细阅读接下来 2-3 份教案，并在「课堂重点」中概括：优先掌握知识点、优先题型、优先题目；题目可分为基础必做、重点突破、选讲拔高。
- 「当堂课掌握情况」新建计划时默认留空，不写“待填写”等占位文字。
- 若教师课后提供错题题号/课堂反馈，必须先结合对应教案或试卷分析错题所属题型、知识点和能力短板，再写入「当堂课掌握情况」，作为后续复习和排课依据。
- 一学期或长周期计划建议每 3-4 次课安排一次复盘/检测课，并优先复习前面「当堂课掌握情况」中记录的薄弱点。

## A4 打印规范

- 页面：A4。
- 方向：课次计划默认横向 `landscape`；摘要类短表可横向或纵向。
- 缩放：适应 1 页宽，页高不限，避免横向断页。
- 页边距：窄边距，建议左右 0.35 英寸、上下 0.45 英寸。
- 打印标题：长表必须重复打印标题行。
- 打印区域：设置到实际内容区域，避免空白列/行被打印。
- 页脚：建议显示 `第 &P 页，共 &N 页`。

## 视觉排版规范

- 标题：首行合并居中，深蓝底白字，字号 16-18，加粗。
- 顶部信息：学生姓名与总课次放在同一行，内容单元格居中展示；阶段目标单独一行，尽量合并横向单元格，便于写较长文字。
- 表头：蓝底白字，加粗居中，建议 11 号。
- 正文：微软雅黑 10-11 号，自动换行，垂直居中；避免字号过小导致打印不清。
- 隔行底色：浅蓝或浅灰，提升可读性。
- 关键提示：可用浅黄底标注阶段目标、考试节点、重要提醒。
- 边框：所有数据区域使用细边框。
- 冻结窗格：长表冻结表头行。
- 列宽：根据内容预设合理宽度，课堂重点列可适当加宽，避免打印后大量截断。
- 行高：课次计划建议 40-55；有较多掌握情况分析的课次可单独加高，避免“字小但空白多”。

## 文件命名规范

- 教学计划：`teaching-plan/plans/{学生}_{阶段名}_教学计划.xlsx`
- 阶段安排：`teaching-plan/plans/{学生}_{阶段名}_课次安排.xlsx`
- 文件名允许中文；如命令行写入中文路径，应通过 UTF-8 脚本处理，避免 Windows 编码问题。

## 技术实现建议

- 使用 `openpyxl` 生成和设置格式。
- 必须设置：A4、打印方向、`fitToWidth=1`、打印区域、重复标题行、自动换行、列宽、边框。
- 若使用公式，必须保证无 `#REF!`、`#DIV/0!`、`#VALUE!`、`#N/A`、`#NAME?` 等错误。
- 教学计划通常不需要公式，优先使用静态文本表格。

## 注意事项

- 不再默认输出 Markdown + Word + PDF 三格式；教学相关表格型成果以 Excel 为统一标准。
- 若用户需要给学生或家长阅读，可在 Excel 中增加「家长版摘要」工作表，而不是另起 Word/PDF。
- 临时脚本统一放入工作区 `_tmp/`，结束后可用 `python .codebuddy/scripts/cleanup_tmp.py` 清理。
