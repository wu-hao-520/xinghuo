# 教案解析与元信息抽取要点

教师提供的教案格式多样（PDF / Word / Markdown），需要从中抽取结构化元信息，用于建立教案索引。

## 需要抽取的字段

| 字段 | 说明 |
|------|------|
| `title` | 教案标题 |
| `subject` | 学科（语文/数学/英语/物理/化学） |
| `grade` | 适用学段（小学/初中/高中 + 年级） |
| `knowledge_points` | 核心知识点（数组，尽量细分） |
| `difficulty` | 难度（基础/中等/较难/难题） |
| `lesson_count` | 预计课时数 |
| `summary` | 一句话简介 |
| `file` | 原始文件名 |

## 不同格式的解析方式

### PDF（.pdf）
- 先判断是文字版还是扫描版：用 pdfplumber/pypdf 提取文字，若为空则是扫描版。
- 扫描版：用 pypdfium2 渲染成图片，再视觉识别（与 `exam-paper-analyzer` 相同）。
- 从正文提取标题（通常第一行/大字号）、教学目标、重难点。

### Word（.docx）
- 用 python-docx 读取段落，提取标题（Heading 样式）、正文。
- 教案通常有固定结构：课题 → 教学目标 → 重难点 → 教学过程 → 作业。

### Markdown（.md）
- 直接读取，标题 `#`/`##` 通常是课题和小节。

## 知识点抽取要点

1. **看「教学目标」或「重难点」**：教案里明确写的知识点最可靠。
2. **看标题**：如《二次函数最值专题》→ 知识点「二次函数」「最值」。
3. **学科术语**：物理看「受力分析/电磁感应/能量守恒」，数学看「函数/几何/概率」，化学看「方程式/守恒/实验」等。
4. 知识点要**细分**到能和学生错题的 `knowledge_point` 对齐（方便匹配）。

## 难度判断

- 看教案的适用对象（如"基础班""提高班""压轴题"）或教学目标表述。
- 无明确标注时，根据知识点本身的难度经验判断（可参考 `student-error-tracker` 的 `references/difficulty_guide.md`）。

## 课时数估计

- 教案有明确课时安排 → 直接采用。
- 无标注 → 按知识点数量估计：1-2 个知识点 ≈ 1 课，3-4 个 ≈ 2 课。

## 建索引注意事项

- 索引文件 `_index.json` 增量更新：新教案追加，已有条目不覆盖。
- 解析后若教师对某教案的元信息有修正（如难度判断不准），以教师意见为准。
- 教案文件名一律英文（避免中文路径乱码），中文标题放 `title` 字段里。
