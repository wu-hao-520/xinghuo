# 五大学科考点/知识点/题型映射（出题与诊断用）

生成变式题、诊断薄弱点时，按学科查找常见考点、知识点与题型的对应关系，确保出的题「同考点、同题型」。

## 语文

- **题型**：选择题、填空题、阅读理解、古诗文默写/鉴赏、文言文翻译、语言文字运用、作文。
- **常见考点→知识点**：
  - 现代文阅读 → 主旨概括、句子含义、表达手法（比喻/拟人/排比）、作用分析、人物形象。
  - 古诗文 → 意象、情感、表达技巧、实词虚词、句式翻译。
  - 语言文字运用 → 病句、成语、衔接、补写、仿写。
  - 作文 → 审题立意、结构、素材、语言。

## 数学

- **题型**：选择题、填空题、计算题、证明题、解答题、应用题。
- **常见考点→知识点**：
  - 代数 → 函数（一次/二次/反比例/指对幂/三角）、方程与不等式、数列、导数。
  - 几何 → 三角形全等/相似、四边形、圆、解析几何（直线/圆/圆锥曲线）、立体几何（空间向量）。
  - 概率统计 → 排列组合、分布、期望方差。
  - 出题要点：换数据、换函数表达式、换几何图形配置，保持方法（配方法、数形结合、辅助线、建系）不变。

## 英语

- **题型**：单选、完形填空、阅读理解、语法填空、短文改错、书面表达、听力。
- **常见考点→知识点**：
  - 语法 → 时态语态、定语从句、名词性从句、非谓语动词、虚拟语气、倒装强调。
  - 词汇 → 词义辨析、固定搭配、短语动词。
  - 阅读 → 主旨、细节、推断、词义猜测。
  - 出题要点：换语境、换例句、换话题，保持语法点/考点不变。

## 物理

- **题型**：选择题（单/多选）、填空题、计算题、实验题、解答题。
- **常见考点→知识点**：
  - 力学 → 运动学（匀变速/抛体/圆周）、牛顿定律、能量与动量、振动波动。
  - 电磁学 → 静电场、恒定电流、磁场、电磁感应、交变电流。
  - 光学/热学/近代物理 → 折射全反射、理想气体、光电效应、能级、核反应。
  - 出题要点：换物理情境、换数据、换设问（正问→反问），保持物理模型（受力分析、过程分析、守恒思想）不变。

## 化学

- **题型**：选择题、填空题、实验探究题、推断题、计算题。
- **常见考点→知识点**：
  - 基本概念 → 物质的量、氧化还原、离子反应、元素周期律。
  - 元素化合物 → 金属/非金属及其化合物性质。
  - 有机化学 → 官能团、反应类型、同分异构。
  - 实验与计算 → 气体制备、物质检验、守恒法/差量法计算。
  - 出题要点：换反应物、换物质、换实验情境，保持守恒思想、配平方法、实验规范不变。

## 通用出题原则

1. **同考点**：新题的 `exam_point` 必须与错题一致。
2. **同题型**：新题的 `question_type` 与错题一致（多选对多选、解答对解答）。
3. **变式不改内核**：换数据、换情境、换设问，但考查的知识点与方法不变。
4. **答案+解析必附**：每题都要有正确答案和详细解析，方便教师批改与讲解。
