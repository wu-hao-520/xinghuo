# 难度分级与出题难度映射

## 难度四级

| 难度 | 特征 |
|------|------|
| **基础** | 单一知识点直接应用，无陷阱，绝大多数学生应得分 |
| **中等** | 单一知识点的变式应用，或两个知识点简单结合，含少量计算/推理 |
| **较难** | 多知识点综合，思维步骤较多，或含明显易错点/陷阱 |
| **难题** | 压轴题，综合性强、方法隐蔽、区分度高 |

## 靶向出题的难度映射规则

生成练习题时，难度调整遵循「同档 / 升一档 / 降一档」：

| 错题难度 | 降一档 | 同档（默认） | 升一档 |
|----------|--------|--------------|--------|
| 基础 | —（已是最低） | 基础 | 中等 |
| 中等 | 基础 | 中等 | 较难 |
| 较难 | 中等 | 较难 | 难题 |
| 难题 | 较难 | 难题 | 难题（可加综合/压轴变式） |

## 升/降一档的具体操作

- **降一档**：减少知识点综合度、简化数据、去掉陷阱、降低思维步骤。
- **升一档**：增加一个相关知识点、加入易错陷阱、加大计算量、换设问角度（正向→逆向）、增加开放性。
- **同档**：保持考查的知识点与方法不变，仅换数据、换情境、换设问角度（即「变式题」的标准做法）。

## 出题难度判断原则

- 教师未明确指定时，默认**同档**出题，先巩固错题对应的知识点。
- 若学生该错题属于「方法不会」，建议先**降一档**夯实基础，再逐步升档。
- 若学生「概念不清」，建议同档换情境，检验是否真正理解而非背答案。
- 若学生「粗心/计算失误」，建议同档或升一档，重点在训练规范与检查。
