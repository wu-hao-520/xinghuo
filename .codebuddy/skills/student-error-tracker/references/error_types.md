# 错误类型分类标准与判断要点

判断学生错题的 `error_type` 是诊断的核心，直接决定后续是「讲概念」「练计算」还是「纠习惯」。分类如下：

## 六大错误类型

| 错误类型 | 典型表现 | 后续应对 |
|----------|----------|----------|
| **概念不清** | 对定义、定理、公式的理解有偏差；张冠李戴；把相似概念混淆（如"核子平均质量"当"平均结合能"） | 重新讲透概念，正反例辨析 |
| **方法不会** | 完全没思路、空着、瞎写；知道考点但不会套用方法 | 讲通性通法，给解题套路 |
| **计算失误** | 思路对、式子对，但数值算错、符号错、单位错 | 练计算习惯、规范步骤 |
| **审题偏差** | 看错条件、漏掉关键信息、误解题意 | 训练审题（划关键词、复述题意） |
| **粗心** | 简单题做错、抄错数字、涂错选项、非能力问题 | 纠习惯、检查清单 |
| **时间不足** | 会做但没时间做，考试策略问题 | 训练时间分配、做题节奏 |

## 判断要点

1. **看学生答案与正确答案的差异**：
   - 多选漏选/多选 → 优先考虑「概念不清」或「审题偏差」，再看漏掉的是不是易错点。
   - 单选选错但方向对 → 可能「计算失误」或「概念不清」。
   - 解答题过程对、结果错 → 「计算失误」。
   - 解答题空着/只写公式没展开 → 「方法不会」。

2. **结合题目难度与学生水平**：
   - 难题做错 → 可能正常（方法不会/概念不清），重点看基础题是否也错。
   - 基础题、中等题做错 → 更可能是「粗心」或「概念不清」，需警惕。

3. **不确定时**：向教师询问该生做错时的真实原因（是没听懂、算错、还是没时间），或先标注「待确认」，待重做时再判断。

4. **一个错题可能有复合原因**：优先选最主要的一个作为 `error_type`，次要原因可写进 `tags` 或 `review_history` 的 note。

## 常见误区

- 把所有错题都归为「粗心」→ 掩盖了真实的概念或方法问题。
- 难题错就一律「方法不会」→ 可能是概念基础没打好。
- 只记对错、不记错因 → 无法针对性复习。

**原则**：错误类型要能指导行动。记下的每个 `error_type`，都应该能回答"下次遇到同类题，我要提醒学生注意什么"。
