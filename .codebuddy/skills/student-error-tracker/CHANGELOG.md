# Skill 变更记录（CHANGELOG）

本文件记录 `student-error-tracker` 这个 Skill 在**每次实际使用过程中对自身**
（结构 / 功能 / 脚本 / 参考文档 / SKILL.md）所做的修改。

## 为什么需要这份记录

- 后期优化 Skill 时，能快速知道「哪些部分被动过、为什么动」，避免盲目改动主体结构导致功能损坏。
- 维护记录仅保留在本文件，不写入最终的学生档案或练习单（这些只面向教师交付学情内容）。

## 记录格式（每次修改追加一条）

```text
### YYYY-MM-DD
- **改动位置**：<文件 / 章节 / 脚本名>
- **改动内容**：<做了什么>
- **改动原因**：<为什么>
```

> 追加新条目时请放在「变更历史」下方的最新位置（即紧跟在本说明之后），保持从新到旧排列。
