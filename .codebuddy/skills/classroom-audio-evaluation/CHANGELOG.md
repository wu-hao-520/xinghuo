# Skill 变更记录（CHANGELOG）

本文件记录 `classroom-audio-evaluation` 这个 Skill 在**每次实际使用过程中对自身**
（结构 / 功能 / 脚本 / 参考文档 / SKILL.md）所做的修改。

## 为什么需要这份记录

- 后期优化 Skill 时，能快速知道「哪些部分被动过、为什么动」，避免盲目改动主体结构导致功能损坏。
- 维护记录仅保留在本文件，不写入最终的听评课报告（报告只面向教师/学生交付听评课内容）。

## 记录格式（每次修改追加一条）

```text
### YYYY-MM-DD
- **改动位置**：<文件 / 章节 / 脚本名>
- **改动内容**：<做了什么>
- **改动原因**：<为什么>
```

> 追加新条目时请放在「变更历史」下方的最新位置（即紧跟在本说明之后），保持从新到旧排列。

### 2026-09-05
- **改动位置**：`SKILL.md`（第一步「音频转写」新增「长录音必读：练习段/静音段幻觉误判」避坑规则）
- **改动内容**：新增一条高优先级避坑规则——1对1 课堂"讲→练习→讲评"结构中，学生练习段声音轻，Whisper（尤其 base）会把低音量底噪转成"固定短语机械重复"（如"法定人數不足"），并把练习段之后老师恢复讲解的内容也一并吞成噪音；规则给出 4 步处理法（识别幻觉特征 → 用 small 模型只重转噪音段之后 → 用 silencedetect/segments 定位边界 → 报告区分"有效授课时长"与"练习段"）
- **改动原因**：本次处理李施恩/何安然「初三数学·菱形」290MB 长录音（120 分钟）时，base 模型把练习段 + 后续 43 分钟讲评吞成"法定人數不足"噪音，导致第一版报告误判课堂仅 14 分钟、严重低估（78 分），用 small 重转后才还原完整课堂（修正为 86 分）；这是"下次必遇"的高频场景，需固化为规则避免重蹈覆辙

- **改动位置**：`references/paths/subjects.md`（新增「六、生物」科目）
- **改动内容**：新增高中生物科目路径规则——公式渲染按需 LaTeX（遗传概率式/数量关系式/反应方程式）、考情对标采用「知识点/概念 + 考频 + 层次」表、特有评价点（生命观念/结构与功能观/图文转换/遗传计算/实验探究）、转写误差高发词（细胞→期包、染色体→来设体、四分体→四分底、减数分裂→军整分内、同源染色体→团院的地子、交叉互换→饭加工换、孟德尔→孟宅等）
- **改动原因**：本次处理吴浩/梁倩仪「高一生物·减数分裂」听评课，生物为新科目，原 subjects.md 无生物路径；粤语/粤普口音 + 快速转写模型致术语大面积音近错字，固化还原词表供后续复用
