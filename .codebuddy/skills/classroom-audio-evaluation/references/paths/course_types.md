# 课型路径

决定「课堂导入 / 例题讲解 / 变式选题 / 模块小结 / 作业布置」五个环节的评价侧重。同一学科同一学段，课型不同则评分侧重不同。

## 一、新授课

- **导入（5 分）**：情境导入重要——激活旧知、创设情境、吸引兴趣；生硬开场扣分明显。
- **例题讲解（40 分）**：侧重**概念建构**与知识铺垫是否充分；步骤逻辑是否完整。
- **变式选题（10 分）**：以基础变式为主，验证概念是否真懂。
- **模块小结（5 分）**：概念小结，明确「是什么、怎么用」。
- **作业布置（5 分）**：基础巩固作业。

## 二、习题讲评课

- **导入（5 分）**：可简要回顾知识点/上题结论，**不强求情境**；直接讲题可接受但需有衔接。
- **例题讲解（40 分）**：侧重**方法对比、思路引导、一题多解**，重难点与易错点突出。
- **变式选题（10 分）**：变式迁移、举一反三，检验方法是否掌握。
- **模块小结（5 分）**：通法小结，归纳解题路径。
- **作业布置（5 分）**：同梯度变式作业。

## 三、错题讲评课

- **导入（5 分）**：回顾错因（针对学生具体错误），无需情境，但需点明「为什么错」。
- **例题讲解（40 分）**：侧重**针对错因、易错点避雷、概念纠偏**；反复纠错、让学生复述。
- **变式选题（10 分）**：同类变式 + 纠错训练，防止同类错误复发。
- **模块小结（5 分）**：易错点小结，归类错误类型。
- **作业布置（5 分）**：纠错 + 同类巩固作业。

## 四、复习课

- **导入（5 分）**：框架导入（知识体系/思维导图）。
- **例题讲解（40 分）**：侧重**知识体系整合、综合运用**。
- **变式选题（10 分）**：综合变式，跨知识点串联。
- **模块小结（5 分）**：体系小结，梳理知识网络。
- **作业布置（5 分）**：综合作业。

## 使用方式

- 评分前先判定课型（从转写内容判断：是否讲错题、是否复习旧知、是否讲新概念）。
- 按本文件对应课型的侧重，调整五个环节的评分严格度与改进建议侧重点。
- 课型不明时默认按「习题讲评课」处理。
