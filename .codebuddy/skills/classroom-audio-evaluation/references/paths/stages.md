# 学段路径（小学 / 初中 / 高中）

决定「考情对标基准、命题趋势关键词、层次侧重、术语风格」。考情对标诊断时按对应学段执行，不用高中标准去套小学。

## 一、小学（对标小升初）

- **考试基准**：小升初衔接考试；基础概念、计算、简单应用题为主。
- **命题趋势关键词**：基础夯实、学习习惯、概念辨析、计算规范、读题审题。
- **层次侧重**：以基础层为主、中档为辅，**慎用拔高**；重点看基础概念是否讲清、习惯是否养成。
- **术语风格**：生活化、直观、具体（可用实物/画图辅助解释）。
- **典型考点示例**：因数与倍数、质数合数、分数小数、几何初步、行程/工程/和差倍应用题、鸡兔同笼等。
- **转写误差高发**：数学术语易被音近字替代（质数→支速/支出/字数、倍数→背处/背书、奇数→记住、合数→口数）。

## 二、初中（对标中考）

- **考试基准**：中考；章节核心知识 + 综合运用。
- **命题趋势关键词**：立德树人、情境化、素养导向、语篇运用（英语）、几何代数综合（数学）。
- **层次侧重**：基础 + 中档为主，适度拔高。
- **术语风格**：规范学科术语，逐步过渡到抽象表达。
- **典型考点示例**：
  - 数学：方程与不等式、一次/二次函数、几何证明、圆、统计概率。
  - 英语：非谓语动词、动名词作介词宾语、比较级最高级、使役动词、宾语从句、时态。
- **转写误差高发**：中英混读（考点→烤点、副词→负质、修饰→修飞）。

## 三、高中（对标高考）

- **考试基准**：高考；高频核心考点、通性通法、能力区分。
- **命题趋势关键词**：反套路、素养导向、跨模块综合、情境建模、通性通法。
- **层次侧重**：中档 + 拔高，强调方法本质与逻辑链。
- **术语风格**：严谨、抽象、符号化。
- **典型考点示例**：
  - 数学：直线与斜率、空间向量基本定理、函数导数、圆锥曲线、数列。
  - 物理：牛顿运动定律、受力分析、动量守恒、电磁场。
  - 化学：化学方程式配平、离子方程式、工艺流程、化学平衡。

## 使用方式

- 做「考情对标诊断」时：先用本文件的考试基准定调（小升初 / 中考 / 高考），再叠加科目路径的考点库。
- 写「课堂亮点 / 改进建议」时：术语与表述风格与本学段一致，避免用高考语言评小学课堂。
