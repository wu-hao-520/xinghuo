# 听评课多路径适配路由表

## 目的

不同「学段（小学/初中/高中）× 科目（数学/英语/物理/化学/语文）× 课型（新授课/习题讲评/错题讲评/复习课）」的评课基准不同。过去 AI 需临时按自身知识适配，导致同一类音频处理方式不稳定、易漏维度、术语不统一。

本路由表将差异固化为**多条可复用路径**：AI 在深度分析前，依据输入信息自动选择路径组合，**无需每次修改 skill 主体**。

## 路径组成

| 路径 | 文件 | 决定内容 |
| --- | --- | --- |
| 学段路径 | [paths/stages.md](paths/stages.md) | 考情对标基准（小升初/中考/高考）、命题趋势关键词、层次侧重、术语风格 |
| 科目路径 | [paths/subjects.md](paths/subjects.md) | 公式渲染方式、考点库形式、科目特有评价点、转写误差高发词 |
| 课型路径 | [paths/course_types.md](paths/course_types.md) | 导入/讲解/变式/小结/作业五个环节的评价侧重 |

## 路由规则

1. 读取输入信息：**学段、科目、课型、学生成绩**（缺项则跳过对应诊断维度）。
2. 组合路径 = 学段路径 + 科目路径 + 课型路径（三者叠加，不冲突）。
3. **评分骨架不变**：三大板块（教学环节 75 / 教学风格 10 / 学生反馈 15 = 100 分）与两个附加诊断（学情 10 / 考情 10）为所有路径共用，见 [evaluation_criteria.md](evaluation_criteria.md)。
4. **考情对标** = 学段路径（考试基准）+ 科目路径（考点库形式）共同决定。
5. **公式渲染** = 科目路径决定（数学/物理/化学用 LaTeX，英语/语文不用）。
6. **环节侧重** = 课型路径决定（如错题讲评课的「导入」可弱化，重点在易错点避雷）。
7. **报告语言与术语** = 学段路径 + 科目路径共同决定。
8. 学生成绩有则做**学情适配诊断**，无则跳过并标注「信息未提供」。

## 扩展方式（新增科目/课型时）

- 新增科目：在 [paths/subjects.md](paths/subjects.md) 追加一节，**不改动其他文件**。
- 新增课型：在 [paths/course_types.md](paths/course_types.md) 追加一节。
- 调整某学段基准：只改 [paths/stages.md](paths/stages.md) 对应小节。

## 学生成绩输入归一化（学情适配前置）

无论用户提供「具体分数」还是「等级」，均统一折算为**得分率**后再分层：

| 原始输入 | 归一化方法 |
| --- | --- |
| 具体分数（如 35/150） | 得分率 = 35 ÷ 150 ≈ 23.3% |
| 等级 A | 映射 ≥ 85% |
| 等级 B+ | 映射 70%～85% |
| 等级 B | 映射 55%～70%（结合录音口述分数可微调） |
| 等级 C | 映射 < 55% |

分层与 ZPD 判定标准见 [evaluation_criteria.md](evaluation_criteria.md) 第四节。
