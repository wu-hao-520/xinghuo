# 答案与解析

## 第 1 题答案：C

**解析**：
- **A 错**：$0\sim t_0$ 段加速，正电荷沿电场线方向（电势降低方向）运动，从 P 到 Q 电势降低，$\varphi_Q<\varphi_P$，Q 点电势比 P 点低。
- **B 错**：$t_0\sim 2t_0$ 段匀速，合力（电场力）为零，$E=0$，电场强度最小而非最大。
- **C 对**：P 点（$t_0$ 处）与 Q 点（$2.5t_0$ 处）由速度图像对称性 $v_P=v_Q$，动能相等 → 电势能相等。
- **D 错**：加速段与减速段的 $v\text{-}t$ 斜率绝对值不同，电场强度不同。

**考点回顾**：$v\text{-}t$ 图斜率 → 加速度 → 电场力 → 场强；速度相等 → 动能相等 → 电势能相等。

## 第 2 题答案：ABD

**解析**：
- **A 对**：氢原子能级是量子化的，跃迁辐射的能量不连续，光谱为线状谱。
- **B 对**：从 $n=4\rightarrow n=3$，轨道半径减小，电子动能 $E_k=\dfrac{ke^2}{2r}$ 随半径减小而增大。
- **C 错**：$n=4\rightarrow n=1$ 的能量差最大，辐射光子频率最高；$n=3\rightarrow n=2$ 能量差较小，不是频率最高。
- **D 对**：截止电压 $U_c=\dfrac{h\nu-W}{e}$，频率越高截止电压越大；$n=4\rightarrow n=1$ 频率最高，对应截止电压最大。

**考点回顾**：能级差越大 → 光子频率越高 → 截止电压越大；电子动能随轨道半径减小而增大。

## 第 3 题答案：AD

**解析**：
- **A 对**：刚进入磁场时，安培力 $F=\dfrac{B^2L^2v_0}{R}$，加速度 $a=\dfrac{F}{m}=\dfrac{B^2L^2v_0}{mR}$。
- **B 错**：进入过程中磁通变化 $\Delta\Phi=BL^2$，电荷量 $q=\dfrac{\Delta\Phi}{R}=\dfrac{BL^2}{R}$，不是 $\dfrac{2BL^2}{R}$。
- **C 错**：完全进入磁场后磁通量不变，无感应电流、无安培力，线框保持进入时的速度匀速，速度仍为 $v_0$。
- **D 对**：若磁场宽度小于 $2L$，线框进入再穿出磁场，末速度减为 0，焦耳热等于动能减少量 $Q=\dfrac{1}{2}mv_0^2$。

**考点回顾**：进入磁场过程的电量 $q=\dfrac{\Delta\Phi}{R}$（磁通变化是 $BL^2$ 不是 $2BL^2$）；能量守恒算焦耳热。

## 第 4 题答案

**(1) $n=2$**

**解析**：光垂直 MN 射入不偏折，沿水平方向射到半圆 PQ 上某点，入射角为 $\theta$。恰好一半光线能从半圆弧边界射出 → 到达半圆的光线中，$\sin\theta\geq\sin C$（全反射）的占一半。半圆上各点入射角从 $0$ 到 $90^\circ$ 均匀分布，$\sin\theta\geq\sin C$ 的比例 $=\dfrac{1-\cos C}{1}=\dfrac{1}{2}$，得 $\cos C=\dfrac{1}{2}$，$C=60^\circ$，故 $n=\dfrac{1}{\sin C}=2$。

**(2) $t=\dfrac{8R}{c}$**

**解析**：全反射临界角 $C=60^\circ$，光在介质中速度 $v=\dfrac{c}{n}=\dfrac{c}{2}$。从 MN 到 PQ 的水平距离为 $2R$，光线发生一次全反射后返回 MN，总路程为 $4R$，故 $t=\dfrac{4R}{c/2}=\dfrac{8R}{c}$。

**考点回顾**：全反射临界角 $\sin C=\dfrac{1}{n}$；「1/2 射出」用几何概率与临界角建立关系；光在介质中速度 $v=\dfrac{c}{n}$。
