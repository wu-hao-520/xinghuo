**综合得分：71 / 100（等级 B+，良好）**

> 附加诊断：学情适配 8 / 10、考情对标 8 / 10（独立呈现，不并入百分制总分）。

**一句话总评**：本节英语习题讲评课聚焦「非谓语动词」这一中考高频核心考点，教师知识功底扎实、解题方法引导到位，"谓语/非谓语判断法"与"动名词 vs 不定式六大意义区别"的口诀归纳清晰，且反复让学生复述、翻译、造句以验证理解；但全程中英混读偏重、口语重复较多，缺少情境导入、系统小结与明确作业，训练停留在单句/短语层面，未上升到语篇，对 B+ 学生的综合运用挑战不足。

### 教学亮点（5 条）

1. **"先判谓语 / 非谓语"的解题思路讲得透**：开篇即以"这里全都是考非谓语动词"点明考点，反复用"如果是非谓语，它怎么可能会用 get 这种词"引导学生先锁定谓语、再判断非谓语形式，是语法填空的通性通法。
2. **动名词 vs 不定式的意义区别归纳成口诀**：把 remember / forget / stop / try / mean / go on 六组易混动词的"doing = 已做 / to do = 未做"对比讲清，并用"remember doing 是已经做了，remember to do 是还没做"落到记忆锚点。
3. **重视"真懂而非蒙对"**：高频使用"你要跟我讲，我要确保你是懂怎么用，而不是蒙的"，让学生当场复述、翻译、造句，理解验证意识强。
4. **举例贴近生活、句式地道**："I am very glad to see you""The T-shirt is too big for me to wear""run fast enough to catch the bus"，把抽象结构落到可迁移的真实句型。
5. **梯度递进清晰**：从"表目的 → 固定搭配 → 意义区别 → 被动 being done → too...to / enough...to"，由易到难层层推进，覆盖非谓语动词的主要考法。

### 改进建议（5 条）

1. **用完整语篇承载非谓语语法**：中考考查的是"语篇型语法填空 / 完形 / 阅读"，建议把六组易混动词嵌入一篇短文，让学生在上下文逻辑中选 doing / to do，而非孤立单句判断。
2. **控制中英混读、术语规范表达**：全程"doing / to do / 非谓语 / 谓语"等术语与中文混杂、口语重复（"我我我""对不对"）较多，建议统一术语口述（如"动名词""不定式"），提升示范语言的可模仿性。
3. **追问从"确认式"转向"开放式"**：把"对不对""懂吗"替换为"为什么这里用 doing 而不是 to do""换成 remember to do 句意怎么变"，逼出学生的归因表达。
4. **补系统小结与板书结构化**：结尾用"判谓语 → 定意义 → 选形式"三步法或一张对比表（doing=已做/to do=未做）收口，而非口头一句"我讲一下重点"。
5. **布置可检验的作业**：明确"把六组动词各造 2 句（doing/to do 各 1）+ 1 篇语篇型语法填空"，并说明次日检查方式，替代"把不认识的划下来"这类模糊要求。
