## 二、整体评价

**综合得分：73 / 100（等级 B+，良好）**

> 附加诊断：学情适配 8 / 10、考情对标 8 / 10（独立呈现，不并入百分制总分）。

**一句话总评**：本节语文课聚焦「写人叙事散文阅读」这一中考现代文高频文体，教师目标意识强，开篇即亮出"分清主次事件找线索、概括人物形象、把握作者情感"三条主线与"叙述手法"一条隐藏任务，知识铺垫扎实（散文 vs 小说的文体差异、抓关键句找线索的阅读方法），并为"细节描写的作用"归纳出"先判手法 → 找关键词 → 析内容 → 说形象情感"的清晰答题步骤；但对 B+ 学生"不会精读文章、审题不细"这一真实短板，教师更多停留在口头催促"多看文章"，缺少"如何精读、如何定位关键词句"的具体示范，课后讲评语气偏急躁，且课堂缺少系统小结与明确作业，隐藏任务（铺垫 / 对比 / 烘托 / 伏笔照应）因时间关系未展开。

### 教学亮点（5 条）

1. **目标意识强、任务分层清晰**：开篇明确列出四个学习目标，并分为"主线任务"（主次事件与线索、人物形象、作者情感）与"隐藏任务"（叙述手法），让学生一开课就清楚"这节课要学到什么"。
2. **文体辨析与阅读方法铺垫到位**：先讲清"散文写人叙事要饱含情感、事件可以碎片化，小说情节要完整"的文体差异，再给出"抓中心句 / 矛盾句 / 抒情句、找感情凝聚点、找明线暗线"的散文阅读路径，为新授做了扎实铺垫。
3. **答题步骤模板归纳清晰**：讲"细节描写的作用"时给出"先判断是动作描写还是神态描写 → 找关键词 → 分析内容特点 → 落到人物形象 / 心情 / 情感"的四步法，是中考赏析题的通性通法。
4. **反复强调审题与易错点**：多次提醒"审题一定要对，第一步做错了这一半的分就没了""概括人物形象要结合具体事例、角度要多、用词要准确"，纠偏意识强。
5. **复习与新授自然衔接**：以"检查笔记 + 回顾回忆性散文 / 人物传记 / 新闻阅读 + 古诗默写检测"开场，自然过渡到"写人叙事散文"，实现了旧知激活，也兼顾了基础积累的习惯管理。

### 改进建议（5 条）

1. **把"多看文章"落实为可操作的阅读步骤**：学生短板是"不会精读、抓不住关键词句"，建议示范"先圈人物、再划描写动词与神态词、边读边批注情感词"的具体动作，而非仅口头催促"你多看几遍文章"。
2. **控制情绪、用正向引导替代指责**：课后讲评中"你鬼叫什么""被你气死了"等用语偏严厉，易让学生产生挫败感，建议改为"我们一起再读一遍这一段，你来找找哪个词最能体现祖父……"式的引导。
3. **补足模块小结与明确作业**：本课缺少系统的板书式小结与课后作业，建议结尾用"人物形象四步 / 细节描写四步 / 标题含义表层+深层"一张答题模板收口，并布置"1 篇同类散文限时阅读 + 古诗默写滚动"的可检验作业。
4. **增加变式题量、拉开梯度**：从"例题讲解"到"学生独立做题"之间变式偏少，建议增设 1～2 道同考点变式（如"神态描写的作用""标题的作用"），检验方法是否真正迁移。
5. **补讲"隐藏任务"叙述手法**：铺垫 / 对比 / 烘托 / 伏笔照应仅作为"隐藏任务"点题未展开，建议单列一节或作为下节课重点，避免"抛出目标却未兑现"。

## 四、学情适配诊断（8 / 10，附加维度）

- **学生水平分层**：B+（良好层，得分率 70%～85%）→ 应"中档为主、适度拔高"。
- **当堂内容难度**：散文阅读方法、概括人物形象、细节描写赏析、标题含义均属"中档"核心考点；散文 vs 小说文体辨析、叙述手法（铺垫 / 对比 / 烘托 / 伏笔照应）偏"拔高"。

- **评级**：**基本匹配（8 分）**——内容难度与方法主体匹配，但精读能力补足不足、个别环节情绪急躁。

**调整建议**：在讲评与练习中，把"多看文章"换成"三分钟精读法"（圈人物 → 划描写动词 / 神态词 → 批注情感词），让 B+ 学生的短板落到可执行、可检验的步骤上。

## 六、短期教学规划指导（未来 2～4 周）

> 学生 B+（七年级升八年级语文），薄弱点集中在「精读能力弱（不会看文章 / 抓不住关键词句）+ 审题不细 + 答题写不到点上」，正适合以中考现代文阅读高频考点为突破口。

### （一）近期目标（量化、可检验）
