## 二、整体评价

**综合得分：50.5 / 100（等级 C，待改进）**

> 附加诊断：学情适配 6 / 10、考情对标 7 / 10（独立呈现，不并入百分制总分）。

**一句话总评**：本节课围绕「直线的倾斜角与斜率」这一高频核心考点，教师耐心细致、知识铺垫充分；但针对 35 分（得分率 23.3%，C 层）学生，讲解偏"自问自答式灌输"，在"倾斜角定义"上反复纠缠却未给出可操作的判断步骤，核心目标未能达成，且无作业、小结仓促。

### 教学亮点（4 条）

1. **知识铺垫充分、有针对性**：开课先复习倾斜角定义、范围（$0^\circ \le \alpha < 180^\circ$）、$k=\tan\alpha$ 与两点斜率公式，再进例题，以学生已有基础为起点。
2. **即时补漏意识强**：发现学生连"二四象限"都记不清，立即停下带学生重新回顾。
3. **善用画图化解抽象**：反复画坐标图，用"向上部分与 x 轴正方向"直观刻画倾斜角，方向正确。
4. **耐心、有温度**：学生多次答不上，教师仍保持耐心，有"你别笑我"的轻松互动，无不耐烦情绪。

### 改进建议（4 条）

1. **给概念配"判断口诀"**：把倾斜角定义固化为"①找 x 轴正方向 → ②找直线向上方向 → ③夹的小于 180° 的角"三步，让学生照着做，而非反复口头辨析。
2. **变"教师讲"为"学生做"**：每讲完一步让学生自己画、自己说，教师再纠正，减少"能不能明白"式自问自答。
3. **主线归到斜率公式应用**：倾斜角辨析点到为止，把时间还给 $k=\dfrac{y_2-y_1}{x_2-x_1}$ 的直接代入，这才是高频得分点。
4. **补作业与小结**：结尾明确布置 3～5 道同考点基础题，并归纳"求斜率"通法落到纸面。
